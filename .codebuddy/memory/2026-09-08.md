# 2026-09-08

## 预请求脚本：CryptoJS / SHA-256 签名怎么写
- 用户贴了一段 Postman 预请求脚本（`CryptoJS.SHA256(...)` + `pm.request.headers.add`），问在 Hoppscotch 里怎么改。
- 事实核对：本 fork 的 `hoppscotch-js-sandbox` **完全没有 CryptoJS**（无 crypto-js 依赖，全仓库无引用），只有 WebCrypto 模块 `cage-modules/crypto.ts`（`crypto.subtle.digest/getRandomValues/randomUUID`）。
- `pm.request.headers.add/upsert/remove` 等在 `bootstrap-code/pre-request.js` 的 Postman 兼容层里**已支持**（走 `hopp.request.setHeader`，大小写不敏感 upsert，新增 header 默认 active）。但只在 experimental 沙箱（默认开启，`EXPERIMENTAL_SCRIPTING_SANDBOX` 默认 true）存在。
- experimental 路径把脚本包成 `await (async function(){...})()`，所以**支持顶层 await**。
- **坑**：沙箱内 faraday-cage 的 `TextEncoder` polyfill，`encode()` 返回的是「只有数字键、没有 length/迭代器」的普通对象 → `Array.from(new TextEncoder().encode(s))` 得到空数组，digest 出空串哈希（e3b0c442...）。解决：脚本里手写 UTF-8 编码（`encodeURIComponent` + 逐字节解析 `%XX`）。
- 已用临时 vitest 验证（跑完即删）：手写 utf8Bytes + `crypto.subtle.digest("SHA-256", bytes)` + `pm.request.headers.add`，生成结果与 node `crypto` 的 sha256 hex 大写一致。
